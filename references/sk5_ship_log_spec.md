# Seekrieg 5 (SK5) 标准船表（Ship Log Sheet）字段规范与推演规则映射

本文档总结 SK5 船表转录标准、字段语义及与 SK5 规则手册、图表集（Game Charts 5th Printing）的对应关系。

---

## 一、 船表顶层与火控修正栏

原页修正栏：`Crew | Sea | BR | Targ Sz | Ops | Captain`

1. **Crew（舰员素质）**：
   - 查 **Table B2**（Crew Rating Determination），掷 d100 决定（如 +3, +2, +1, 0, -1）。
2. **Sea（海况对火炮射击修正）**：
   - 查 **Table C4** 下半部（Gunnery Reduction），根据蒲福风级（Beaufort Force）与战舰总 DP 查出负修正（如 -1, -2），填入 Sea 栏。
3. **BR（战斗因数 Battle Rating）**：
   - `BR = Crew + Sea`，计算后填入，推演中固定不变（中规 §3.2.7/§10.2.9）。
4. **Targ Sz（目标尺寸）**：
   - 船表自带印制值（如战列舰为 3），作为被射击时的基础修正（中规 §3.2.7/§6.1.1）。
5. **Ops（舰上作业削减率 % Reduction in Operations）**：
   - 查 **Table C4** 上半部（中规 §3.2.7/§10.2.8），根据蒲福风级与战舰总 DP 查出削减百分比（如 10%、15%、20%）。
   - **实战影响**：最高航速降低 X%、火炮各距离射速降低 X%、可用损管等级值 DCR 降低 X%、防空等级降低 X%、舰载机弹射起飞与回收判定率降低。
6. **Captain（舰长/指挥官修正）**：
   - 查 **Table B1**（Command Rating Determination）或历史剧本预设（中规 §2.4/§3.2.12/§4.2）。
   - 掷 d100 决定舰桥命令值（BCR）、旗舰命令值（FCR）以及战术/火控特质修正（如 +1, 0, -1）。若舰长阵亡，副长（XO）立即重掷 Table B1。

## 二、 武器与战斗系统

### 1. 主炮 / 副炮（Primary & Secondary Batteries）
- **Damage Factor (DF，损伤因数)**：击穿装甲后代入 **Table K4** 换算损伤点数（DP）与暴击效应（DE）。
- **FCS 与 FC Radar 拆分**：
  - `火控系统`：填写火控计算机型号（如 `1A3 Mark 3 (FC)`、`2A3 Mark 4 (FD)`）。
  - `火控雷达`：单独列出加成（如 `FC Radar + 2`）。
- **弹药种类 (Shell Types)**：标准四分类：`AP`（穿甲）、`SAP`（半穿甲）、`COM`（普通）、`HE`（高爆）。
- **穿透表（Penetration Table）**：
  - 列出各距离下的最大射速（ROF，发/分/管）、距离等级（S 短、M 中、L 长、E 远）、水平穿深（H，英寸）、垂直穿深（V，英寸）。
- **火控表（Fire Control Table）**：
  - 按 5 个目标航速带（0–9, 10–18, 19–27, 28–36, 37–45 节）与 4 个距离等级（S, M, L, E）查出两组数字：`宽舷角基础值 / 窄舷角基础值`（窄舷角定义：目标舰艏/舰艉左右偏离 30° 范围内，即 60° 扇区）。

### 2. 速射炮（Rapid Fire Batteries, RF）
- **对空射击**：按 5 个高度带（S 超低空, L 低空, M 中空, H 高空, V 超高空）分别列出左舷（Port）与右舷（Stbd）的防空值（AA Rating）。
- **对海射击与简化火控值（Table W1）**：
  - 炮表中出现的两组数字（如 `9/7`、`13/10`）为简化火控表底数：
    - 前值为**宽舷角（Broad Aspect）**基础值，后值为**窄舷角（Narrow Aspect）**基础值。
    - 第一行（Max Rg）用于超出有效射程但在最大射程内；第二行（Eff Rg）用于在有效射程内（中规 §3.2.9）。

### 3. 舰载机（Aircraft）
- 记载要素：载机数、弹射器数、机型、**攻击 / 防御 / 升限等级（如 1 / 1 / 25）**、极速 / 巡航速度、最高升限。

## 三、 防御、损伤与机动系统

### 1. 装甲表（ARMOR）
- **装甲质量系数**：基准为 1.00（中规 §3.2.13）。
- **9 大命中部位（Table J1 映射）**：
  - 水平部位：`1H` 甲板 (DECK)、`2H` 炮塔顶 (TURRET)、`3H` 上层建筑水平 (SUPERSTR)。
  - 垂直部位：`4V` 司令塔 (CON)、`5V` 中部主带 (BELT MID)、`6V` 端部主带 (BELT END)、`7V` 炮座 (BARBETTE)、`8V` 炮塔立面 (TURRET)、`9V` 上层建筑立面 (SUPERSTR)。
  - 穿透判定：炮弹穿深 ≥ 有效装甲厚度即判定为击穿（Penetration），转入内部暴击；< 有效厚度为未击穿（Non-penetration）。

### 2. 总体损伤等级（TIER / DP 表）
- **格式与语义**：`等级 / DE 检定率 (Tier)` + `累计 DP`（如 `1 / 70` 对应 352 DP）。
  - **规则机制（中规 §8.5.2）**：当战舰累计承受的 DP 达到该级阈值时，掷 **d100** 检定。若结果 **≤ 该级检定率数字**（如 01–70），则触发总体损伤效应（DE），对 **Table L** 的 **G 列（总体）** 掷骰确定具体效应编号，再查 **Table M1** 执行。
  - **多等级与沉没（§8.5.3）**：单回合越过多个 Tier 需对每个 Tier 逐一掷骰检定 DE，但应用 M1 描述时统一采用达到的最高 Tier 等级。单回合越过 **8 个或更多 Tier 直接判定沉没**。
  - **士气检定（§8.6）**：越过 **Tier 7** 时必须对 Table M4 进行士气检定，失败则舰员弃舰。

### 3. 动力与推进衰减（Machinery Spaces）
- `Engine Rm`（轮机舱）、`Prop/Shaft`（推进轴系）、`Boiler Rm`（锅炉舱）在 SEV0–SEV5 状态下的极速折损阶梯。
- **机舱进水沉没检定（§8.5.4）**：进水受损机舱数达到总机舱数（轮机舱 + 锅炉舱）的 **80%** 时，每回合必须掷 d100 检定，01–75 即开始下沉。

### 4. 操舵、加速与指挥
- **加速限制**：按低速段与高速段分段限制每回合最大加速度（节/回合）。
- **转向角**：标准舵（Standard Turn）最大 45°/回合（移动距离折算 75%）；急舵（Emergency Turn）最大 90°/回合（移动距离折算 50%）。
- **BCR / FCR / DCR**：由 Table B1 / B3 决定初始值，受战损（DE）影响递减。
