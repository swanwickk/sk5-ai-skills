## 🏛️ 第一部分：运动学

### 1. 运动学与航迹计算
- **时间标尺**：每回合固定为 **2 分钟**；
- **转向折算**：
  - $\le 15^\circ$：实际移动距离不缩减（100%）；
  - $> 15^\circ$：标准舵（Standard Turn）折算 **75% 航程**，急舵（Emergency Turn）折算 **50% 航程**；
- **渐进分段（Advance 前冲）**：转向按角度拆分段数，第 1 段强制沿原航向直行（模拟舵效响应前冲），从第 2 段起均分剩余角度；**段数表（TURNING SEGMENTS）**：
  - ≤10°：直接转（1段，不拆分）；
  - 11°–15°：2段，不降实际移动距离（100%）；
  - 16°–45°：2段；
  - 46°–90°：3段；
  - 91°–135°：4段；
  - 136°–180°：5段；
  - ＞16°统一折算：凡16°以上转向，标准舵一律 75% / 急舵一律 50%（适用于以上所有≥16°档）；
- **极速截断与航速性质铁律**：指令航速超出船表设计极速（Max Speed）时，自动截断（Clamp）在最大极速执行。**转向与机动规避（EX）只折算/缩减当回合实际移动距离，严禁降低单位航速数值（Speed 字段恒保持实际执行航速，如 35kt/36kt）**。
- **鱼雷危险区长方形覆盖铁律**：鱼雷危险区为**长方形几何体**——长度为鱼雷当分钟实际推进距离，宽度为雷道中心线向两侧延伸的扇面总宽度（宽扇面±750码/标准±500码/窄±250码）。**严禁对雷头前向未推进至的区域进行命中检定**；只有舰船航迹/位置落入该长方形覆盖域内才算进入危险区。

### 2. 鱼雷扇面危险区宽度
- **宽扇面（Wide Spread）**：`1,500 码`（半宽 750）；**标准扇面**：`1,000 码`（半宽 500）；**窄扇面**：`500 码`（半宽 250）。
- 鱼雷实体存档格式见 sk5-simplot-format。

### 2.5 🔴 鱼雷发射前置命令（TR → TL）
- **TR(X)——鱼雷准备**：必须在发射（TL）**前一个回合**下达，指明发射方位（P/S/B/N）；
- **TL(X)——鱼雷发射**：仅有前置 TR 才合法；**跨回合未 TL 则 TR 失效**，须重新下达 TR；
- **判非法处理**：未下 TR 直接 TL → **TL 命令忽略**（鱼雷不发射），机动/炮击等其余命令照常执行（同 FL 非法命令忽略先例）；
- 发射当回合鱼雷在移动阶段开始时放置并与舰艇同步推进 2 分钟航程。

### 6. 🔴 移动完成后的强制检查 SOP（每回合必查，先于侦察/射击结算）
**每回合全部舰船移动结算完成后、进入任何侦察/炮击结算之前，必须按以下顺序强制执行两项检查**（规则 5.1 移动阶段流程）：

#### 6.1 第一查：舰船航迹与鱼雷危险区是否重合
- 逐条舰船逐一核对**本回合移动航迹**与**所有在航鱼雷扇面危险区**（宽扇面 1,500 / 标准 1,000 / 窄扇面 500 码）的空间关系；
- **单位换算铁律**：存档坐标单位 → 码必须除以 **49.37**（100000/2025.37）。比较的是舰雷中心线距离 vs 扇面**半宽**（宽 750 / 标准 500 / 窄 250 码）。直接拿存档单位当码比会放大 49 倍，漏掉全部交汇；
- **判定标准（半段对应＋同分钟同步）**：仅当「舰船前半段轨迹与鱼雷模板前半段在**同一分钟内**相交」或「后半段与后半段在同一分钟内相交」时，才存在被命中危险；跨半段组合（舰前×雷后、舰后×雷前）一律不计；
- **移动与否参与铁律**：**无论本回合有无移动命令，舰船一律参与命中可能性判定**——静止舰危险带的判定对象退化为其位置点；未收到移动命令≠自动豁免。

- **🎲 分段命中判定铁律（用户裁决固化，2026-09）**：回合移动划分为**前半段/后半段**，命中判定分别在**前半段移动结束**与**后半段移动结束**后进行：
  1. **逐步推进法（唯一合法流程）**：记录回合起点位置 → 舰雷双方**同步**推进 1 分钟 → 停在分界点（如 23:25）记录位置，仅用该分钟内的轨迹段检查前半段 → 再同步推进 1 分钟到回合末，检查后半段。鱼雷是单腿（起点→终点取中点切半），舰船按各自带时间戳航迹点切分（23:25 前为前、后为后）；静止舰退化为位置点；
  2. **同分钟同步核＋边界去重**：同一半段内，舰与雷按各自分钟内轨迹以相同时间参数 tau∈[0,1] 同步采样（61 步），取**同分钟最近距离** ≤ 半宽才算相交。**静态整段几何最小距禁用**——它会把跨过分界点的同一个遭遇算两次。判定：后半段最近点落在分界起点（如 23:25:00）且之后单调走远 = 前半段遭遇的尾巴，**不计新进入**；只有首入点 tau 落在本半段内部的才算一次。例：后半段最近点在分界起点且单调走远 → 前半段尾巴，只计前半段一次；
  3. **鱼雷平均分配（每半段分别执行）**：半段移动中若多艘舰艇的位置都与模板相交而有被命中危险，扇面中的鱼雷在舰艇之间**平均分配**：
     - 雷数＝舰数 → 每艘舰艇各检定 1 枚（例：4 舰 4 雷 → 各检 1 枚）；
     - 雷数＞舰数且不能平分 → **占据模板区域面积较大**的舰艇检定剩余鱼雷（例：3 舰 4 雷 → 面积最大的舰艇检 2 枚，其余各 1 枚）；
     - 雷数＜舰数 → 仅**占据模板区域面积较大**的前 N 艘（N＝雷数）舰艇各检定 1 枚，其余舰艇该半段不检定（例：3 舰 2 雷 → 面积最大的 2 艘各检 1 枚）；
  4. **鱼雷数量消耗（组内扣减）**：每半段按第 3 条分配检定，**命中雷移除**，未中雷带入后半段；前半段已检过的雷后半段不重复检，只有后半段**新进入**且组内还有剩余雷时才检。例：4 雷组前半段 2 舰各检 2、中 1，则后半段只剩 3 雷；
  5. **RTE 修正（表 T1）**：只有该雷组**前半段有命中、剩余雷后半段再检**时，RTE +1.0（多次重检按每次 +1.0 累积）；**整轮打空的雷组不加**；
  6. **模板移除**：鱼雷达到最大航程，或推演中不会再命中其他舰艇时，不再对其移动进行追踪，并把模板从推演平面移开；
  7. **单次命中检定（分配到的每枚鱼雷）**：查 **标准表 T1 × T2 → T3** 结算命中率（T1 = 目标速度行 × 射程列的相对跟踪误差因数；T2 = 目标相对雷航向角度 × 目标船长的因数；R = T1×T2，查 T3 对应 ROLL TO HIT，掷 d100 ≤ 上限即命中）；
  8. **命中后流程**：命中 → **T4 哑弹检定**（按国家/时期/引信类型查表，掷 d100 ≤ 阈值为哑弹）→ **T5 伤害**（Damage Class A–I × CON/MAG 查表得 dp）→ **ARMOR ADJUSTMENT 减伤**（D100 判定命中部位 5V/6V/无甲，按装甲厚度减免 dp）→ **表 L 的 T 列掷骰得损伤效应（DE）**（`scripts/sk5_torpedo.py: TORPEDO_L_TABLES/query_l_gft(era,roll,'T')`，era=目标下水年代 1905/1922/1945/CV；查表 M1 描述具体效果，鱼雷命中总使用 A 类命中描述；DE 列有附加损伤效应时总是触发）；
  9. **回合流程时序**：移动阶段仅检查危险区交汇 + 命中判定（T1×T2→T3）；**所有伤害（T4/T5/ARMOR/DE）等到炮击阶段完成后，在统一的损伤阶段结算**。
- **🔴 严禁擅自改用 T7/T8 可选规则**：技能指定标准表 T1/T2/T3；T7/T8 为规则书"可选方法"，**未经玩家明确要求不得代用**（先例教训：T8 射程档会放大近距离命中率且绕过 T2 角度/长度因数，导致静止舰误判命中）。
- **记录**：在裁决存档与报告中明确记录哪舰何时穿越哪个雷群扇面、鱼雷分配结果、RTE 修正及判定结果。

#### 6.2 第二查：舰船之间是否符合碰撞条件
- **两两核对全部在航舰船**（友军与敌军均适用，含同编队）本回合航迹，按第六部分（5.2.8–5.2.10）执行判定；发生碰撞/撞击后**同步更新存档 Speed 字段归零**（细则只保留第六部分，此处不重复）。

## ⚔️ 第三部分：火炮火控与集火解算体系

1. **单回合射速法则 (ROF)**：穿深表所列 ROF 为 2 分钟回合单管弹数，单回合发射总弹数：
   $$\text{发射弹数} = \lfloor \text{ROF} \times \text{参战可用门数} \rfloor \quad (\text{严禁再乘以 2})$$
2. **新目标首轮射速减半**：首回合射击新目标或切换目标时，射速折半（$\lfloor \text{ROF} \times 0.5 \times \text{门数} \rfloor$），且火控修正 $-2$。
3. **火炮射界核验 (Chart G1，全表已录)**：
  - 中线首尾炮塔（含背负）：240°（艏/艉各120°），DD及以下270°；背负2/3号位短距离艏向20°禁射；
  - 中线舯部：舷侧各120°（艏30°偏角至艉30°偏角）；
  - 梯形/舷侧舯部：本舷160°，跨甲板对舷40°（仅中/远，短距离禁跨射）；
  - 梯形/舷侧首尾：本舷自艏/艉起160°，跨甲板对舷110°（仅中/远）；
  - 固定MLR/BLR：首/尾本舷30°，舯部中线两侧各15°；
  - 并列首尾：本舷160°+对舷30°（计190°）；
  - 炮廓首/尾100°、舯部140°。
  - 只有处于射界内的火炮才计入参战门数（短距离无跨甲板射击）。
4. **过度集中射击修正 (Chart H1.6)**：
   - 当 $N$ 艘舰艇在同回合集火同一目标时，**所有 $N$ 艘射击舰在火控中全员均承受 $-(N - 1)$ 的过度集中射击惩罚**，而非仅后射舰承受。
5. **雷达盲射修正 (Chart H1.1e)**：火控修正 $-5$，忽略烟雾修正，火控表强制查 Narrow（窄舷）列。
6. **炮击结算唯一合法算法 = 网站简化法（`scripts/sk5_gunfire.js` + `scripts/sk5_site.js`，逻辑逐字提取自 https://sk5.swanwick.site/；2026-09-03 仅在 DE_TABLE 各 band 的 v 字典追加 G/F/T 三键，判定逻辑一字节未动）**：最终火控 → 千分比 HIT_TABLE → 逐发 D1000 独立判定 → 命中位置/损伤/DE 全走站内表。**严禁再用 H1→I1 二项分布高级法**（已证伪：同输入两套结果不同，网站法为准）。用法：`node scripts/sk5_gunfire.js cases.json [--seed N]`（默认种子 12345 可复现；不传真随机）。字段映射：shell_count＝ROF×门数（新目标折半取整）；base_fc＝船表火控值；`ship_penetration`＝穿透表查表值（定口径→按实际射程在MD船表穿透表距离行内插到0.5档→V部位取V行、H部位取H行，严禁填射程本身；网站报“无对应穿深数据”时回查穿透表，不封顶硬套）；target_distance＝射程带（E→远，M→中，S→近）；evasion 仅目标-3/仅本舰-2/双方-8；fire_history 首次-2/上轮击中+2；normal_fire_groups＝同目标炮组数（含本组）；target_size＝目标 TS；battle_rating＝BR；radar＝火控雷达加成。命中数以 `locations` 有效部位为准，“跨射（未命中）”条目自动排除，不计入。网站改版后重提内联 JS 覆盖 `sk5_site.js` 逻辑段即可（G/F/T 追加段须保留重打），驱动不用动。

## 🛡️ 第四部分：法定穿甲等级、过穿检定与战损体系

每次命中在计算 DP 点数前，必须强制完成穿甲等级（Penetration Class）裁决：

```
【命中部位】 (Chart J1/J2) ──> 查目标该部位有效装甲厚度
      ↓
【装甲 ≤ 0.5"（薄弱/无装甲目标）】 ──> 查 Chart K3 (UNARMORED):
  • AP / SAP: 01-20 Class A (引爆) / 21-00 Class B (过穿未爆)
  • COM: 01-70 Class A / 71-00 Class B
  • HE: 01-90 Class A / 91-00 Class B
      ↓
【装甲 > 0.5"（装甲目标）】 ──> 查 Chart K1 / K2:
  • 穿深 < 装甲: Class C (未穿透)
  • 装甲 ≤ 穿深 ≤ 2×装甲: Class A (穿透引爆)
  • 穿深 > 2×装甲 (情况 X): 查 Chart K2 检定过穿 (AP 01-30 Class A / 31-00 Class B)
```

1. **穿甲等级对伤害计算（Chart K4）的法定影响**：
   - **Class A（穿透引爆）**：造成最大全额爆炸伤害，按 D100 掷骰分档计算高额 DP，DE 触发率最高；
   - **Class B（过穿未引爆）**：炮弹直接穿出舰体，**只造成 Chart K4 Class B 列的固定贯穿结构伤（无需掷骰分档）**，DE 触发率减半；

2. **🔴 关键损伤效应 (DE) 与内嵌全量闭环**：
   - 触发 DE 后立即查 Table L3，若触发次生 DE（如 DE 100 弹药库殉爆、DE 107 卡死、DE 152 起火 Severity 20、*606 结构损毁、*615 电路受损），必须**立即全量投骰闭环结算具体受损炮塔编号与系统数值**，严禁留下未决描述。

## 🌟 第五部分：照明弹（Starshell, IS 命令）与探照灯规则

### 1. 照明弹发射（舰桥命令 `IS#/#`）
- 由 1 座 **4"~6" 口径火炮**发射，参数：方位（以射击舰为中心）+ 距离（码）；
- **距离限制**：不得近于 3,500 码；最远 = 该炮最大射程的 50%，且不得超 10,000 码；
- **方位与距离在射击舰移动阶段结束后测量**；
- **⚠️ 占用炮塔**：发射照明弹的火炮本回合不得再参与任何其他射击（主炮/副炮发射照明弹后该炮直接计入不可用）。

### 2. 照明区域与覆盖判定
- 每枚照明弹照亮一个 **长 2,500 码 × 宽 1,500 码** 的矩形区域（以落点为中心，长轴沿发射方位）；
- **被照亮判定（两条任一成立即视为整个回合被照亮）**：
  - **当前位置判定**：照明弹发射后目标当前（移动后）位置落入照明区域 → **必被照亮**；
  - **航迹判定**：目标当前不在区域内，但**本回合移动航迹的一半以上（≥50%）穿过照明区域** → 同样视为整个回合被照亮；
- **存档标绘**：照明弹落点必须在 SimPlot 存档中以**参考点（Reference Point）实体**标出（`IdNum: Rxxx` + `TextTags.AdditionalText` 标注 "照明区2500x1500码"）。

### 3. 照明效果
- 被照亮的舰艇自动被所有在 Chart D1 视距范围内的舰艇侦测（照明即暴露）；
- 对被照明目标进行炮击时，能见度修正用 Chart H1 的 1b/1c（目标被照明）而非盲射修正。

## 🧨 第六部分：碰撞与撞击判定（5.2.8 – 5.2.10）

### 1. 判定框架（核心铁律）
- 碰撞/撞击使用**波段移动规则**（5.2.7，5 段 × 24 秒）核算两舰接近过程；
- **主动撞击（Ramming, 5.2.9）**：需在命令阶段主动声明撞击意图（占一条桥令），且**全部满足 3 个条件** → 造成损伤（表 X 系列结算）；
- **被动碰撞（Collision, 5.2.10）**：**只满足 3 个条件中的 2 个** → 自动判定碰撞，**无需检查船体是否实际接触、无需额外掷骰**（船体几何接触不是前置条件）；
- **碰撞是"数条件"不是"看船体"**：航迹交叉但条件不足 → 无碰撞；条件满足 2 个 → 即使几何上看似擦过也判定碰撞。

### 2. 撞击 vs 碰撞区别速查

| 维度 | 主动撞击 (Ramming, 5.2.9) | 被动碰撞 (Collision, 5.2.10) |
|---|---|---|
| 触发方式 | 命令阶段主动声明（占 1 条桥令，记录目标） | 自动判定，无需声明 |
| 条件要求 | 3 个条件**全部**满足 | 3 个条件中**满足 2 个** |
| 损伤 | **有**（表 X3/X4/X5 结算 DP） | **无**（0 DP，不触发 DE） |
| 撞击角度 <20° 或 >160° | 不适用（视为碰撞） | 直接视为碰撞 |
| 后果① | 造成 DP + 可能 DE | 下一命令阶段所有桥令重发 |
| 后果② | 双方可能都受损（表 X5） | 回合末航速自动归 0，按加速表重新加速 |
| 结算表 | 表 X2（速度因数）/ X3（损伤因数）/ X4 / X5 | 无掷骰 |

### 3. 撞击三条件（5.2.9）
1. **撞击角度**：> 20° 且 < 160°（目标舰中轴线往内 20° 以外区域）；若 ≤ 20° 或 ≥ 160°（中轴线 20° 以内）直接视为碰撞；
2. **速度条件**：撞击舰航速 ≥ 目标航速 + 6 节；或目标无法响应操舵（CA/CS/CP 命令）且航速低于撞击舰；
3. **距离条件**：回合开始时两舰中心距 ≤ 撞击舰本回合移动距离的 1/2。

### 4. 撞击伤害结算
- 撞击因数 = X1目标速度因数 + X2撞击速度因数（`ram_damage`）；若 ≤ 0 则该撞击无作用；
- 查表 X3（撞击因数 × 撞击角度）得损伤因数 → 表 X4（侧舷装甲厚度）修正；
- 最终 DP = 损伤因数 × 目标总 DP；撞击舰损伤 = 表 X5 修正后因数 × 目标损伤 DP；
- 撞击损伤 ≥ 目标总 DP 的 10% → 自动触发一次 DE（查表 L）；撞击伤害位置只能为 5V 主侧舷或 6V 侧舷端部（舰首/舰尾 15% 内），装甲取船表实际值。

### 5. 被动碰撞后果与处理闭环（5.2.10）
1. **无损伤**（不产生 DP、不触发 DE）；
2. 下一命令阶段，涉事舰艇**所有舰桥命令都必须重新发出**（持续命令 B1D、KX 烟幕等全部失效，须重下）；
3. 回合结束时，涉事舰艇**航速自动变为 0**，之后必须按船表加速表逐回合重新加速；
4. **存档同步**：SimPlot 存档中涉事舰 `Speed` 字段必须置 `0`（坐标/航迹保留不变，`Course` 保留碰撞前航向）；
5. **报告同步**：裁判简报专节记录碰撞事件（含核算表：最近距离、三条件逐条、满足个数）；双方报告：
   - 涉事方（本方）：可明确记录碰撞事故、航速归零、桥令重发提示；
   - 观测方（敌方）：**只能写观测到的事实**——雷达测速显示目标航速骤降/停船【雷达捕获】或目视所见【目视捕获】，**严禁写"碰撞"结论**（双盲原则）。

### 6. ⚠️ 机舱损伤按表核销铁律（Engine Rm / Boiler Rm / Prop-Shaft）
- **每次机舱类 DE（614/612 等）出现一次，就在船表 4.3 动力舱室损伤衰减表对应行划掉一格**：
  - `Engine Rm（轮机舱）`、`Boiler Rm（锅炉舱）`、`Prop/Shaft（推进轴）` 三行各自独立计数；
  - 衰减表形如 `T#=1 | 34 | 0 | 0…`：T# 为该型舱室总数，SEV0~SEV5 为损毁 0~5 格后的航速 KTS；
- **唯一舱室判定**：某行 T#=1（仅一格，如五月雨/白雪的 Engine Rm `[34|0]`）→ **损毁即动力全失，航速直接归 0**（无需再叠加其他 -kt 修正）；
- **多格舱室**：按 SEV 表取对应航速（如 Boiler Rm T#=3 `[34|28|12|0]` 损 1 格 → 28kt）；
- **614 的 Engine vs Boiler 判定**：规则未写明选择方法，标准做法**掷 D100（01-50 轮机舱 / 51-00 锅炉舱）**；掷中结果与船表格数核销；
- **叠加规则**：614 每次触发 = 永久 -1kt（Tier1-7）/ -2kt（Tier8-10）**且** 附加掷骰（T1-3: 01-30、T4-7: 01-60、T8-10: 01-85）命中则再损 1 个机舱；机舱损毁后的航速**以船表 SEV 表为准**（唯一 Engine Rm 损毁则整体归 0，不再叠加 -kt）；
