## D1——白昼水面能见度（SURFACE VISIBILITY-DAYLIGHT）

**原理**：基于观测者高度 vs 目标高度，查出目标**上层建筑（舰桥以上）**可被识别的距离。桅杆和烟囱烟可在更远距离可见。

**查表**：能见度代码（9=极晴，8=晴朗1&2，7=晴，6=轻雾）→ 观测舰目标大小与高度 → 目标目标大小值 → 基础距离（码）

**修正（全部乘法因子）**：

| 条件 | 修正 |
|---|---|
| 目标被地平线暮光照出轮廓 | ×1.20 |
| 目标处于陆地背景前 | ×0.80 |
| 烟囱烟雾和/或高桅杆可见 | ×1.20 |
| 搜索舰艇是非战斗舰艇 | ×0.85 |

## D2——夜间水面能见度（SURFACE VISIBILITY-NIGHT）

**原理**：同 D1，但针对夜间。分两个子表："极晴+月光"和"晴朗+月光"。

**修正（全部乘法因子，共10项）**：

| 条件 | 修正 |
|---|---|
| 目标被燃烧舰船或地平线光亮衬出轮廓 | ×2.50 |
| 目标处于陆地背景前 | ×0.60 |
| 搜索舰艇航速1~15节 | ×1.10 |
| 搜索舰艇停船（听音状态） | ×1.40 |
| 搜索舰艇是非战斗舰艇 | ×0.85 |
| 目标航速低于10节 | ×0.80 |
| 目标航速高于29节 | ×1.20 |
| 无月光 | ×0.60 |
| 能见度代码7 | ×0.90 |
| 能见度代码5~6 | ×0.65 |

D2查出的距离假设**75%发现概率**，实际发现时机由 D4 掷骰决定。

## D3——雷达极限视距（RADAR VISIBILITY）

**原理**：由**地球曲率**决定的雷达视线物理极限。**任何雷达的实际探测范围都不能超出此表。** 这不是一张"搜索能力"表，而是一张硬上限表。

**查表**：雷达天线高度（20/40/60/90/120英尺）→ 目标大小值 → 极限视距（码）。**无修正表。**

实际雷达探测距离还受雷达型号（表 Z4）、目标 RCS、天气（规则10.4）等影响，但永远不会超过 D3。

## D4——夜间发现概率（TARGET DETECTION PROBABILITY - NIGHT）

D2 查出的距离 = 75% 发现概率点。D4 掷骰决定早发现/晚发现：

| 目标相对于D2距离的位置 | 需要掷出 |
|---|---|
| D2距离外5000码以内 | 01-10 |
| D2距离外3000码以内 | 01-40 |
| D2距离±1000码以内 | 01-75 |
| D2距离内4000码以内 | 01-95 |
| D2距离近4000码以上 | **自动发现** |

## D表体系逻辑链

```
D1(昼间目视) / D2(夜间目视) → 你能不能看到目标
D3(雷达极限) → 雷达能看到的物理上限
D4(夜间概率) → 什么时候看到（掷骰）
D5(夜间照明) → 能不能照亮射击
```

**夜间核心链条**：D2（能否看到）→ D4（何时看到）→ D5（能否照亮射击）

## D2 Code 8 基础值（VERY CLEAR WITH MOONLIGHT，码）

**观测者TS=-1（DD, 15ft）：** -1→3,100 | 0→3,400 | 1→3,800 | 2→4,300 | 3→4,700

**观测者TS=0（DD, 30ft）：** -1→3,900 | 0→4,300 | 1→4,700 | 2→5,200 | 3→5,500

**观测者TS=1（CL, 50ft）：** -1→4,800 | 0→5,200 | 1→5,600 | 2→6,000 | 3→6,400

**观测者TS=2（CA, 80ft）：** -1→5,800 | 0→6,200 | 1→6,600 | 2→7,100 | 3→7,400

**观测者TS=3（BB, 110ft）：** -1→6,700 | 0→7,000 | 1→7,400 | 2→7,900 | 3→8,300

Code 7 = 上述值 × 0.90

## ⚠️ 翻译陷阱

中文规则书对 D1 修正的翻译可能使用了加法表述（如"+12000码"），但英文原版明确为乘法因子（如"×2.50"）。查阅规则时**务必对照英文原版 Game Charts**。

## ⚠️ 海里→码换算（血泪教训）

**国际海事标准：1 NM = 1,852米 = 2,025.37码**

❌ 严禁使用 1 NM = 6,000 码（这是6,000英尺的误记）

此错误会导致所有距离计算偏大2.96倍，侦察判定完全失真。
