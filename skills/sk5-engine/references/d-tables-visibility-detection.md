## D1——白昼水面能见度（SURFACE VISIBILITY-DAYLIGHT）

**原理**：基于观测者高度 vs 目标高度，查出目标**上层建筑（舰桥以上）**可被识别的距离。桅杆和烟囱烟可在更远距离可见。

**查表**：能见度代码（9=极晴，8=晴朗1&2，7=晴，6=轻雾）→ 观测舰目标大小与高度 → 目标目标大小值 → 基础距离（码）

**修正（全部乘法因子）**：

| 条件 | 修正 |
|---|---|
| 目标被地平线暮光照出轮廓 | ×1.20 |
| 目标处于陆地背景前 | ×0.80 |
| 烟囱烟雾和/或高桅杆可见 | ×1.20 |
| 搜索舰艇是非战斗舰艇 | ×0.85 |

## D2——夜间水面能见度（SURFACE VISIBILITY-NIGHT）

**原理**：同 D1，但针对夜间。分两个子表："极晴+月光"和"晴朗+月光"。

**修正（全部乘法因子，共10项）**：

| 条件 | 修正 |
|---|---|
| 目标被燃烧舰船或地平线光亮衬出轮廓 | ×2.50 |
| 目标处于陆地背景前 | ×0.60 |
| 搜索舰艇航速1~15节 | ×1.10 |
| 搜索舰艇停船（听音状态） | ×1.40 |
| 搜索舰艇是非战斗舰艇 | ×0.85 |
| 目标航速低于10节 | ×0.80 |
| 目标航速高于29节 | ×1.20 |
| 无月光 | ×0.60 |
| 能见度代码7 | ×0.90 |
| 能见度代码5~6 | ×0.65 |

D2查出的距离假设**75%发现概率**，实际发现时机由 D4 掷骰决定。

## D3——雷达极限视距（RADAR VISIBILITY）

**原理**：由**地球曲率**决定的雷达视线物理极限。**任何雷达的实际探测范围都不能超出此表。** 这不是一张"搜索能力"表，而是一张硬上限表。

**查表**：雷达天线高度（20/40/60/90/120英尺）→ 目标大小值 → 极限视距（码）。**无修正表。**

实际雷达探测距离还受雷达型号（表 Z4）、目标 RCS、天气（规则10.4）等影响，但永远不会超过 D3。

## D4——夜间发现概率（TARGET DETECTION PROBABILITY - NIGHT）

D2 查出的距离 = 75% 发现概率点。D4 掷骰决定早发现/晚发现：

| 目标相对于D2距离的位置 | 需要掷出 |
|---|---|
| D2距离外5000码以内 | 01-10 |
| D2距离外3000码以内 | 01-40 |
| D2距离±1000码以内 | 01-75 |
| D2距离内4000码以内 | 01-95 |
| D2距离近4000码以上 | **自动发现** |
