# SK5 炮击命中与损伤计算器技能 (SK5 Gunfire Calculator)

本技能依据玩家在推演回合下达的交火命令、战场环境态势以及由 `sk5-ship-log-reader` 生成的双方标准 Markdown 船表，**先全局统筹战术修正，再严格调用 SK5 炮击计算器 1.7 官方算法矩阵**，精准计算出水面火炮的命中数、命中部位、穿透判定、DP 结构破坏及严重损伤（DE）效果。

---

## 核心红线与行为准则

1. **绝对零脑补，信息缺失即刻阻断**：
   - 严禁擅自假设施加任何未由玩家说明或船表中未列出的数据（如自行假设交战距离、目标朝向、弹种、雷达开机状态等）。
   - **缺失信息阻断机制**：只要计算所需前置要素不全，必须立即暂停计算，清晰列出缺失项向玩家索取，待玩家补齐后再继续。
2. **全局统筹优先（Cross-Ship Holistic Coordination）**：
   - 炮击解算绝不能单对单孤立进行。在投骰计算具体炮组前，**必须先统筹全场所有交火线**，统计跨舰火力集中、多舰围攻、战场烟雾、全场照明与机动状态。
3. **严格以玩家输入与上传船表为唯一依据**：
   - 计算器的所有参数输入严格对应船表实印数据与规则公式，不得修改或偏离 `sk5.swanwick.site`的判定准则。

---

## 炮击计算标准作业流程 (SOP)

### 阶段 1：前置完整性核查（Completeness Pre-check）
在开始计算前，逐一核对以下 4 类要素是否完备：
1. **交战双方**：射击舰与目标舰（必须已加载双方标准 MD 船表）。
2. **射击几何态势**：交战距离（具体码数，或明确的短 S / 中 M / 长 L / 远 E 档位）、目标相对朝向投影（宽舷 Broad / 窄舷 Narrow）。
3. **参战武备与弹药**：开火炮组（主炮 / 副炮 / 具体门数或炮塔）、选用弹种（AP / SAP / COM / HE）、开火模式（正常向 / 密集向 / 弹幕射击）。
4. **环境与战术状态**：能见度等级（1–9）、时间与光照（昼间 / 晨昏 / 夜间 / 月光 / 探照灯 / 照明弹）、烟雾标记（战斗烟雾 / 烟幕）、双方规避机动状态（EX 命令）、射击历史（转移新目标 / 上回合已命中 / 持续锁定）、目标是否起火（DE≥50）。

> ⚠️ **阻断提示**：若发现缺少任何一项（例如：“未指定使用主炮还是副炮”、“未说明目标是宽舷还是窄舷”），立刻回复玩家：“⚠️ 缺少关键推演要素：[列出具体缺项]，请补充后继续解算。”

---

### 阶段 2：全场态势统筹与修正规划（Holistic Modifiers）

在解算每门炮前，统一汇总并计算以下 10 项标准修正值（表 H1 / 计算器引擎）：

| 修正项 | 规则编号 | 统筹判定逻辑 | 修正值范围 |
|---|---|---|---|
| **1. 炮火集中与弹幕** | H1.6 / `over_concentration` | **统筹全场射向该目标的炮组总数**：<br>• 正常向炮组数 $N_{norm}$：超出 1 组的每组 $-1$；<br>• 密集向/弹幕炮组数 $N_{conc}$：每组 $-2$；<br>• 修正值 $= -(N_{norm} - 1) - 2 \times N_{conc}$（最大惩罚上限 $-6$）。<br>*射向该目标的所有舰艇炮组均统一承受此惩罚。* | $0 \sim -6$ |
| **2. 遭受多舰围攻** | H1.5 / `firing_under_fire` | **统筹全场被攻击舰艇**：<br>若本舰在本回合被 **3 艘或以上** 的敌舰开火攻击，本舰射击任何目标均承受惩罚。 | $-2$ 或 $0$ |
| **3. 目标尺寸** | H1.7 / `target_size` | 取目标船表的 `Targ Sz` 印制值（战列舰通常为 3，驱逐舰 1–2，鱼雷艇 -1）。 | $-1 \sim +5$ |
| **4. 战斗因数 (BR)** | H1.9 / `battle_rating` | 取射击舰船表：`Crew（舰员素质）` + `Sea（海况对射击影响）` 之和。 | $-4 \sim +3$ |
| **5. 火控雷达** | H1.10 / `radar` | 取射击舰主炮/副炮数据栏中的 `FC Radar` 加成值（如 `+2`）。 | $0 \sim +3$ |
| **6. 规避机动** | H1.3 / `evasion` | 无 (0) / 仅目标规避 (-3) / 仅本舰规避 (-2) / 双方规避 (-8)。 | $0 \sim -8$ |
| **7. 射击历史** | H1.4 / `fire_history` | 首次射击或本回合转火新目标 (-2) / 持续跟踪 (0) / 上轮命中目标 (+2)。 | $-2 \sim +2$ |
| **8. 战场烟雾** | H1.2 / `smoke` | 视线穿过的战斗烟雾数量（$-1$/个） + 锅炉/烟幕数量（$-3$/个）。 | 负数累加 |
| **9. 环境与光照** | H1.1 / `visibility` | 能见度档位 (8–9: +1, 6–7: 0, 4–5: -2, 1–3: -4) + 昼夜/月光/太阳方位/照明弹/探照灯/目标起火修正。 | 综合结算 |
| **10. 基础火控** | §3.2.5 / `base_fc` | 查射击舰火控表：依据目标航速档（0–9 到 37–45 节）与距离档（S/M/L/E），按目标投影（宽/窄）取出基础值。 | 正整数 |

**最终综合火控值**：
$$\text{Final FC} = \text{Base FC} + \sum \text{Modifiers}$$

---

### 阶段 3：逐炮组命中与穿透伤害解算（Combat Execution）

#### 步骤 3.1：发射弹数与命中判定
1. **发射弹数**：$\text{Shell Count} = \text{当前距离 ROF} \times \text{参战可用炮管数}$（向下取整）。
2. **查命中表（Table I1 / `HIT_TABLE`）**：
   - 依据 `Shell Count` 与 `Final FC` 查表投骰，得出**实际命中弹数（Hits）**。若命中为 0，本次射击结算结束。

#### 步骤 3.2：命中部位判定（Hit Location）
对每一枚命中弹，依据目标投影朝向掷 d100 查 **Table J1**：
- **宽舷表 (`HIT_LOCATION_BRD`)** / **窄舷表 (`HIT_LOCATION_NRW`)** / **航母表 (`HIT_LOCATION_CV`)**
- 得出具体命中部位代码：`1H 甲板`、`2H 炮塔顶`、`3H 上层建筑水平`、`4V 舰桥`、`5V 主装甲带`、`6V 装甲带末端`、`7V 炮座`、`8V 炮塔立面`、`9V 上层建筑垂直`。

#### 步骤 3.3：装甲穿透比对（Penetration Resolution）
1. **火炮穿深确定**：
   - 若使用穿甲类弹（AP/SAP/COM）：取射击舰在该距离下的穿深（垂直部位 4V–9V 比对 V，水平部位 1H–3H 比对 H），并经弹种系数调整（Table J3）。
   - 若使用高爆弹（HE）：查高爆弹穿深表（`HE_PEN_TABLE`），按火炮口径确定穿深。
2. **装甲比对**：
   - 提取目标船表该部位的**有效装甲厚度**。
   - **击穿（Penetration）**：$\text{穿深} \ge \text{装甲厚度}$。
   - **未击穿（Non-penetration）**：$\text{穿深} < \text{装甲厚度}$。

#### 步骤 3.4：破坏点数（DP）与损伤效应（DE）判定
1. **查伤害表（Table K4 / `DAMAGE_TABLE`）**：
   - 依据火炮伤害因数（DF）、命中部位及击穿状态，掷骰查得单发造成的 **DP 损伤点数**。
2. **严重损伤（DE）与暴击检定**：
   - 若命中产生击穿，查 **Table L3 (`DE_TABLE`)** 投掷特定部位的暴击效果（DE# 编号），并调取 **Chart M1 (`DE_TEXT`)** 输出具体受损系统与严重等级（Severity）。
   - 将累加 DP 与目标船表的 **Tier 损伤表** 阈值比对，若跨越 Tier，按船表印制的检定率掷 d100 判定总体损伤效应。
