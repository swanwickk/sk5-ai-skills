# SK5 船表读取与标准转录技能 (SK5 Ship Log Reader)

本技能用于将玩家上传的 **Seekrieg 5 (SK5)** 战舰船表（Ship Log Sheet，PDF 或图像格式）精确提取、解析并转录为结构化的 **标准 Markdown 船表** 与 **SK5 炮击计算器（sk5.swanwick.site）速填卡**，作为下游 AI 兵棋推演、状态跟踪与火控计算的权威数据源。

---

## 核心红线（五大铁律）

1. **绝对零脑补与严禁合成 Fallback（Zero Hallucination & No Synthetic Fallback）**：
   - **严禁按口径/年代预设推断火控表（FCT）与穿透表（Penetration Table）**！
   - 官方双页大舰船表文本/矢量层中 100% 包含实印的 `PENETRATION TABLE` 与 `FIRE CONTROL TABLE`，必须通过物理坐标聚类算法逐格提取原页实印数值。
   - 若属于单页小艇（无主炮穿透表），必须规范标记为 *“主武器为速射炮(RF)/鱼雷，火控查 Table W1”*，绝不凭空编造大口径穿深或通用火控。
2. **海战兵棋中文舰名优先（Chinese Naming Principle）**：
   - 舰船文件名统一采用 `[中文舰名]_[英文安全名]_[年代范围]_标准船表.md`。
   - 船表主标题统一采用 `# [中文舰名]号 ([前缀] [英文名], [舰型]) 标准船表`。
3. **版式自适应识别（Dual-Layout Segmentation）**：
   - **双页主力舰/主力驱逐舰**：第 1 页为进攻与战斗系统，第 2 页为防御、机动与损管系统。
   - **单页独立小艇（特征：左上角带国旗/舰徽位图）**：如早期鱼雷艇/驱逐舰（DD-1）、炸药炮巡洋舰（Vesuvius）、撞角巡洋舰（Katahdin），单页即为完整船表，严禁与下一页强行合并！
4. **严格三源分流（Three-Source Separation）**：
   - **原页实印值**：照录原页字面值（如穿透深度、有效装甲、总 DP、Target Sz 3 等）。
   - **推演前查表生成项**：必须标明对应的官方图表编号（如 Crew 查 Table B2、Sea/Ops 查 Table C4、BCR 查 Table B1）。
   - **推演现场填写项**：推演未开始前必须保持空白（如 BCR、DCR、Captain 签名等留空）。
5. **路径与字符绝对安全（Path & String Safety）**：
   - 生成文件名与落盘路径时，必须对舰名中的 `/`、`\`、`(`、`)` 进行安全清洗（如 `Preble (DD 345/DM20)` -> `Preble_DD_345_DM20`），严禁导致操作系统子目录路径错误。

## 提取与转录 SOP 标准流程

### 步骤 1：PDF 页面切片与版式自适应判定
1. 遍历 PDF 页面，检测 `SHIP LOG SHEET` 标记。
2. **切片决策状态机**：
   - 若 `Page[i]` 包含 `SHIP LOG SHEET` 且 `Page[i+1]` 亦包含 `SHIP LOG SHEET`（或 `Page[i]` 为最后一页），判定为 **单页独立小艇版式**。
   - 若 `Page[i]` 包含 `SHIP LOG SHEET` 且 `Page[i+1]` 为背面（不含表头），判定为 **双页大舰版式**，合并 `(Page[i], Page[i+1])` 为一艘。

### 步骤 2：物理坐标表格精准抓取（BBox / Word Clustering）
由于 PDF 文字流存在多列重叠与旋转，直接提取可能错行，必须使用 PyMuPDF `page.get_text("words")` 进行物理坐标聚类：

1. **穿透表（PENETRATION TABLE）实印直采**：
   - 定位 `Yds` 锚点列（`2,000`, `4,000` ... `36,000` 码，`x ≈ 167` 或 `x ≈ 331`）。
   - 沿 y 轴公差 5.0pt 提取同行对应数值：`ROF (dx < 15)`、`Rge S/M/L/E (15 <= dx < 26)`、`水平穿深 H (26 <= dx < 38)`、`垂直穿深 V (38 <= dx < 55)`。
2. **火控表（FIRE CONTROL TABLE）实印直采**：
   - 定位 `Short` 锚点（`x ≈ 78` 或 `x ≈ 243`）。
   - 在 `[x+5..x+75, y-90..y+20]` 区域内按 y 坐标 6pt 聚类出 8 组（5航速区间）共 40 个火控底数：
     - `0: Ext_N`, `1: Ext_B`, `2: Long_N`, `3: Long_B`, `4: Med_N`, `5: Med_B`, `6: Short_N`, `7: Short_B`。
   - 组装为标准 5×4 矩阵：`0-9`, `10-18`, `19-27`, `28-36`, `37-45` 航速带下的 `(Broadside / Narrow)`。
3. **装甲矩阵（1H–9V ARMOR）实印直采**：
   - 从第 2 页提取 `ARMOR`（有效装甲厚度）与 `Actual`（实际装甲厚度），提取 9 大部位（1H甲板、2H炮塔顶、3H上层建筑水平、4V司令塔、5V主装带、6V端部装甲、7V炮座/机库立面、8V主炮立面、9V上层建筑垂直）。
   - 航母自动映射为 1H飞行甲板、2H机库甲板、3H主甲板、7V机库立面。

### 步骤 3：单页小艇与速射炮系统提取
1. 单页小艇（如 `Farragut TB11`、`Bainbridge DD1`）提取：
   - 身份、排水量、舰员、长宽吃水、航速、DP、DCR（印制值）、燃料代码。
   - **近程速射炮（RF1 / RF2 / RF3）**：型号、最大射程、有效射程、左右舷 5 高度带 AA/RF 点数、Table W1 简化火控基础值（如 `9/7`, `13/10`）。
   - **鱼雷与深弹**：管数（TT）、备弹、鱼雷型号、设定射程/航速、损伤等级（Damage Class）。
   - **TIER 损伤表与动力衰减**：提取原页实印 DP 阶梯与轮机/锅炉舱衰减。
   - 装甲厚度规范填充为 `0.0`。

### 步骤 4：生成标准 Markdown 与 JSON 交付物
调用 `build_sk5_all.generate_ship_md(s)` 生成六章格式标准文档，并生成 SK5 炮击计算器（`sk5.swanwick.site`）即用 JSON 速填卡。
