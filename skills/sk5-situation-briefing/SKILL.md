# SK5 海战兵棋局势简报与受损报告撰写技能 (SK5 Situation Briefing)

本技能定义了在 **Seekrieg 5 (SK5)** 兵棋推演中，如何依据回合机动、水下鱼雷航迹、侦察、炮击计算及总体损伤（Tier）判定结果，规范撰写 **裁判全局战局简报（Master Briefing）** 与 **单方双盲态势简报（Double-Blind Situation Briefing）** 的标准作业流程（SOP）。

---

## 总则（3 条，违反即返工）

1. **无源不写**：一切描写须有引擎判定结果或玩家命令为数据来源；引擎没判出的起火/爆炸/拉烟/倾斜/航速变化严禁写入。
2. **双盲隔离**：单方报告只写本方已知情报；敌目标一律以「敌 + 舰种 + 战术编号」指代（如“敌驱逐舰 tn 1131”），禁敌舰名/敌坐标/敌火炮型号；禁“遭我方命中”“判为中度受损”等裁判结论。
3. **有数写数**：凡有数值的（DP、战损率、Tier、方位、距离、剩余航程）必须写具体数字，禁“严重”“多处”“数个”等笼统词。

---

## 报告结构（6 章）

### 【第一章 🚢 舰队各舰当前航态与状态】
以结构化表格呈现全舰队各舰（含已战沉舰）：
`舰名 | 舷号 | 战术编号 (TN) | 当前航向 | 实战航速 | 战备/战损状态 | 舰体完整度`

### 【第二章 📡 本回合舰队侦察结果】
- 时间戳置顶（如 `23:18`）；
- 每艘己方舰独立一段，该舰每个探测目标写一行：`手段：尺寸（tn XXXX），方位 XXX，距离 X.X 海里`（手段 = 雷达/目视/火光；同目标多手段合并如“雷达+目视”）；
- 例：「雷达探测：小型目标（tn 1131），方位 022，距离 7.2 海里」；
- 无接触的舰写「未探测到任何目标」一句收尾。

### 【第三章 💥 本回合舰队射击结果】
- 写清弹种（如 16″ AP、5″ HE、三式烧霰弹等）；
- 雷达盲射写弹着水柱回波与目标覆盖情况；
- 目视写起火/爆炸**仅当同时满足**：引擎判出火灾（Severity）或殉爆（DE 100），**且**目标在本方目视距离内；否则瞭望哨写「未见异常」一句收尾。

### 【第四章 🛡️ 舰队被攻击与战损情况】
- **4.1 本回合被攻击情况**：仅列本回合受攻击舰，每舰一段，按顺序写：攻击口径/弹种与命中N发/近失N发 → 本回合新增 DP（穿甲等级 Class A/B/C）→ 逐个 `DE XXX — 效果（含部位编号/严重度/持续状态）` → 火灾状态（新起火写严重度+是否挂船体起火标记；续燃写本回合 DP 与灭火掷骰）→ 累计 DP / 总 DP / 战损率 / 当前 Tier / Tier 检定结果。受击无损照写前两项并注明本回合 DP=0。战损率 = 累计DP ÷ 总DP × 100%（保留1位小数）。段末正文写 `其他单位均报告未受到攻击。`
- **4.2 全舰队累计受损汇总**：战役迄今战沉舰（沉没回合与原因）与受损舰的累计 DP、战损率、Tier、极速折损、关键受损系统；与 4.1 同舰数字必须一致。

### 【第五章 📊 弹药存量】
全舰队主炮、副炮、鱼雷分弹种列消耗量与剩余量。

### 【第六章 🌊 在航鱼雷与装填追踪】
- 每组在航鱼雷：编号、已航行距离、剩余射程（码）、折合剩余回合数；
- 装填状态：「正在装填，剩余 X 回合（第 Y 回合就绪）」/「已重新装填好」/「管内满载」；
- 擦舷鱼雷：观察舰、方位、数量估算、掠过距离；
- 沉没回波规则：弹药库爆炸或连越 8 Tier 者次回合移除回波；其余 DD/CL 掷 1D6×10 分钟、CA 及以上掷 1D10×10 分钟后彻底沉没，半程时回波变小可判正在下沉。

---

## 损伤判定

完整规则（穿甲等级 K1-K3、DE 闭环、Tier 沉没）唯一权威源在 sk5-engine §第四部分。报告端补充两条：DE 写“某座炮塔失能”时立即投骰定具体炮塔编号；所有次生检定（起火 Severity、卡死率、进水率）当回合投骰闭环。

**文风**：紧凑干练，有情况写实况，没情况写“未见异常”；同舰禁负面罗列多个“未见/无”。

|---|---|---|
| 1 | 敌舰名零容忍 | 全文搜索敌方每一舰名 → 必须为 0 |
| 2 | 禁裁判结论 | 搜索“命中/击中” → 只出现在 4.1；搜索“似乎/可能/推测/判为” → 改写为事实 |
| 3 | 侦察完整 | 第二章每目标有手段+指代+方位+距离；每舰独立一段 |
| 4 | 损伤完整 | 4.1 每舰五要素齐全、无损舰四项齐全；DE 均带编号；分 4.1/4.2；4.1/4.2 同舰数字一致 |
| 5 | 弹药分弹种 | 第五章无“待查” |
| 6 | 鱼雷追踪 | 第六章每组有剩余码数与装填状态 |
| 7 | 零编造 | 每个起火/爆炸/拉烟/倾斜描写逐条比对引擎输出：须引擎判出 AND 目标在目视距离内，缺一删 |
| 8 | 纯文本格式 | 叕回合侦察报告无 Markdown 标题/表格/加粗 |
